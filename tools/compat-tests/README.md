# اختبارات توافق النظام

هذه برامج اختبار مستقلة لـWindows64، وليست مكونات تُثبت مع النظام. شغّلها في جهاز افتراضي مع قرص A قابل للكتابة. لا تستخدم ملفات المستخدم.

```sh
x86_64-w64-mingw32-gcc waittest.c -Os -s -o waittest.exe
x86_64-w64-mingw32-gcc waitmany.c -Os -s -o waitmany.exe
x86_64-w64-mingw32-gcc pipetest.c -Os -s -o pipetest.exe
```

- `waittest.exe`: الحجم غير المقبول، اختلاف القيمة، المهلة، وإيقاظ دون تغيير القيمة. النتائج في `A:\waittest.txt`.
- `waitmany.exe`: 30 جولة، في كل جولة 8 خيوط انتظار. يوقظ خيطا واحدا ثم البقية، والقيمة لا تتغير. النتائج في `A:\waitmany.txt`، والصفر يعني عدم رصد فشل.
- `pipetest.exe`: يترك ReadFile معلقا على pipe، ثم يقيس GetFileType من خيط آخر. يفك القراءة بعد 300ms حتى لا يترك الاختبار معلقا في النظام القديم. النتائج في `A:\pipetest.txt`.

الأزمنة تقريبية تحت المحاكاة. انتظار 20ms في اختبار الخيوط يقلل سباق بدء الاختبار، لكنه ليس اختبار سباقات شاملا. لم تُختبر كل حالات المقابض أو إنهاء الخيوط قسريا.

- `storageprobe.c`: اختبار متتابع لملفات مخصصة تحت `C:\KushStorageTest` فقط. ترجمة: `x86_64-w64-mingw32-gcc storageprobe.c -O2 -s -o storageprobe.exe`. النتائج على الشاشة؛ صفر فشل لا يثبت سلامة SQLite أو IndexedDB أو التزامن أو تحمل انقطاع الطاقة.
