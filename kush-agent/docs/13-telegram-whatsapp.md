# 13 — التواصل مع الوكيل من تيليغرام وواتساب

ترسل المهمة برسالة، والوكيل ينفذها على جهاز Kush ويرد عليك في نفس المحادثة:
- رسالة "بدأت المهمة" + ملاحظات النموذج أثناء العمل (💬).
- **طلبات الموافقة بأزرار** (موافقة / رفض) للأفعال الحساسة.
- النتيجة النهائية + **صورة الشاشة**.

```
أنت:    افتح Notepad واكتب قائمة المشتريات
الوكيل: بدأت المهمة على kush1 بالنموذج deepseek ⏳
الوكيل: 💬 أفتح قائمة ابدأ وأبحث عن Notepad
الوكيل: 🔐 الوكيل يطلب موافقتك …   [موافقة] [رفض]
الوكيل: المهمة اكتملت ✅  تم فتح Notepad وكتابة القائمة.  [صورة الشاشة]
```

## الأوامر (عربي أو إنجليزي)
| الأمر | العمل |
|---|---|
| أي نص | مهمة جديدة (و `@deepseek …` أو `@claude …` لاختيار النموذج) |
| `/screen` أو «الشاشة» | صورة الشاشة الآن |
| `/status` أو «الحالة» | حالة المهمة الحالية |
| `/stop` أو «إيقاف» | إيقاف المهمة |
| `/vms` أو «الأجهزة» | قائمة الأجهزة |
| `/vm kush2` أو «جهاز kush2» | اختيار جهاز آخر |
| «نعم» / «لا» | الرد على آخر طلب موافقة (بديل الأزرار) |
| `/help` أو «مساعدة» | المساعدة |

**الأمان:** فقط المعرّفات في القائمة المسموح بها تستطيع استخدام الوكيل. أي شخص آخر يحصل على رد "غير مصرّح" مع معرّفه، لتضيفه أنت إن أردت.
مهمة واحدة لكل محادثة في نفس الوقت، وكل الأفعال تمر بنفس قواعد الأمان (Policy).

---

## تيليغرام (الأسهل — لا يحتاج دومين)
1. في تيليغرام افتح **@BotFather** ← `/newbot` ← اختر اسماً ← انسخ الـ **token**.
2. على الخادم ضعه في `/etc/kush-agent/env`:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   ```
3. فعّل القناة في الإعدادات (من اللوحة: النماذج والإعدادات، أو `/etc/kush-agent/models.yaml`):
   ```yaml
   channels:
     default_vm: kush1
     telegram:
       enabled: true
       token_env: TELEGRAM_BOT_TOKEN
       allowed_users: []
   ```
4. `systemctl restart kush-admin`، ثم أرسل أي رسالة للبوت. سيرد "غير مصرّح" ومعه **معرّفك** (رقم).
5. ضع الرقم في `allowed_users: [123456789]` وأعد التشغيل. انتهى.

البوت يستخدم **long polling**: يسأل تيليغرام عن الرسائل الجديدة، فلا يحتاج رابطاً عاماً ولا HTTPS.

## واتساب (WhatsApp Business Cloud API من Meta)
يحتاج: **دومين مع HTTPS** (لأن Meta ترسل الرسائل إلى رابط عندك)، وحساب Meta Developer، ورقم هاتف للبزنس.

1. ثبّت اللوحة مع دومين: `sudo DOMAIN=panel.example.com bash deploy/install.sh`
2. في [developers.facebook.com](https://developers.facebook.com): أنشئ تطبيقاً من نوع **Business** وأضف منتج **WhatsApp**.
3. من **WhatsApp ← API Setup**: انسخ **Phone number ID**، وأنشئ **توكن دائم** (System User token بصلاحية `whatsapp_business_messaging`).
4. من **App settings ← Basic**: انسخ **App secret**.
5. في `/etc/kush-agent/env`:
   ```
   WHATSAPP_TOKEN=EAAG...
   WHATSAPP_APP_SECRET=...
   WHATSAPP_VERIFY_TOKEN=...     # يولّده install.sh تلقائياً، أو اختر أي نص سري
   ```
6. في الإعدادات:
   ```yaml
   channels:
     whatsapp:
       enabled: true
       phone_number_id: "1234567890"
       allowed_numbers: ["249912345678"]   # رقمك بالصيغة الدولية بدون + ولا مسافات
   ```
   ثم `systemctl restart kush-admin`.
7. في Meta: **WhatsApp ← Configuration ← Webhook**:
   - Callback URL: `https://panel.example.com/webhooks/whatsapp`
   - Verify token: نفس `WHATSAPP_VERIFY_TOKEN`
   - اشترك في حقل **messages**.
8. أرسل رسالة لرقم البزنس من واتساب.

**ملاحظات واتساب:**
- كل رسالة واردة يُتحقق من توقيعها (`X-Hub-Signature-256` بالـ App secret)؛ غير الموقّعة تُرفض.
- واتساب يسمح للبزنس بالرد بحرية خلال **24 ساعة** من آخر رسالة منك. وهذا مناسب: أنت تبدأ، والوكيل يرد.
- أزرار الموافقة رسائل تفاعلية (reply buttons).
- إصدار Graph API الافتراضي `v23.0`، ويمكن تغييره بـ `api_version` تحت `whatsapp`.
- رقم الاختبار المجاني من Meta يرسل فقط لأرقام تضيفها في قائمة المستلمين في لوحة Meta.

## حالة القنوات
صفحة **نظرة عامة** في اللوحة تعرض كل قناة: متصلة أم لا، وعدد المسموح لهم، وآخر خطأ.

## ما تم اختباره
اختبارات آلية (`tests/test_channels.py`) على QEMU حقيقي مع **محاكاة** لواجهتي تيليغرام وواتساب:
الرفض لغير المسموح، الأوامر، صورة الشاشة، بدء المهمة، أزرار الموافقة والرفض، التقرير النهائي مع الصورة،
التحقق من توقيع واتساب، ووصول الـ webhook بدون تسجيل دخول. **لم يُجرّب مع بوت أو رقم حقيقي بعد** (لا توجد مفاتيح هنا).

## القادم
الرسائل الصوتية (تحويل الكلام لنص بالعربي والدارجة السودانية)، إرسال صور/ملفات للوكيل، والذاكرة والتفضيلات لكل مستخدم.
