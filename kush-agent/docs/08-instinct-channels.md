# 08 — قنوات Instinct (مخطط، غير منفذ بعد)

الهدف: المستخدم **لا يفتح تطبيقاً**؛ يرسل المهمة برسالة أو مكالمة، والوكيل يشتغل على جهاز Kush في السحابة ويرجع له بالنتيجة.

| الميزة | التصميم |
|---|---|
| Messaging Gateway | خدمة واحدة تستقبل واتساب / تيليجرام / SMS وتحوّل كل رسالة إلى `kush-agent run` على جهاز المستخدم |
| الموافقات | سؤال Policy (`ask`) يتحول إلى رسالة بأزرار "نعم / لا" بدل سؤال الطرفية (`Approver` جديد) |
| التحديثات | `on_event` في `Agent` يرسل ملخص التقدم وصورة الشاشة عند الانتهاء أو عند مشكلة |
| مكالمات صوتية | تحويل كلام ↔ نص (عربي ودارجة سودانية) ثم نفس المسار |
| بريد الوكيل | عنوان لكل مستخدم يستقبل أكواد التحقق وتأكيدات الطلبات ويحوّلها لمهام |
| الذاكرة | ملف تفضيلات لكل مستخدم يُضاف للمهمة |
| كلمات المرور | خزنة مشفّرة؛ تُكتب عبر kushagent مباشرة ولا تمر بالنموذج |
| الدفع | بحد إنفاق وبموافقة صريحة دائماً |

نقاط الربط موجودة في الكود: `Approver` (agent/policy.py) و`on_event` (agent/loop.py) و`ControlServer` (server.py).
